# Amdehaymanot-official-website

Official website for Amde Haymanot Sunday School — Jimma Debre Efrata St. Mary Cathedral.

## Stack

- React (Create React App)
- Material UI
- API: `https://api.amdehaymanot.com`

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
